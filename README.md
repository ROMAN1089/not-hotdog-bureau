# Not Hotdog — Бюро контроля сосисок 🌭

Фото → один крайне важный вердикт: **HOT DOG / NOT HOT DOG**.
Русский интерфейс, загрузка с камеры, вероятности двух классов и абсурдный протокол проверки.

## Запуск

Нужен Python 3.11 или 3.12. Из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:7860. При первом распознавании скачивается модель; нужен интернет и свободное место. После загрузки модель работает на CPU, платный API не нужен. Фото не отправляется в модельный API: обработка идёт на машине, запускающей приложение. При размещении на сервере фото передаётся этому серверу.

## Kaggle

В архиве есть `kaggle-demo.ipynb`: включите Internet в настройках ноутбука и выполните ячейки. Ноутбук выводит классы и вероятности для загруженного изображения. Gradio-интерфейс запускайте локально или в отдельном хостинге. Правила AI Without Limits 2027 допускают внешние модели и open-source код с условиями, но описание мероприятия посвящено астрономическим снимкам. Подходит ли хот-дог проект, не подтверждено. Подробности в `KAGGLE-NOTES.md`; этот пакет не является завершённым конкурсным сабмитом.
