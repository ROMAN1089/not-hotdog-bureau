## Запуск

Нужен Python 3.11 или 3.12. Из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Откройте http://127.0.0.1:7860. При первом распознавании скачивается модель; нужен интернет и свободное место. После загрузки модель работает на CPU. Фото не отправляется в модельный API: обработка идёт на машине, запускающей приложение. При размещении на сервере фото передаётся этому серверу.
